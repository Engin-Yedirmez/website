# WildWorld Animal Pages

Welcome to the **WildWorld Animal Pages** project! This website showcases various wild animals with detailed information about each species, including their scientific name, habitat, diet, and fun facts. The pages are designed with HTML, CSS, and a responsive layout for easy navigation.

## Features

- **Home Page**: An overview of the website and navigation to animal detail pages.
- **Animal Detail Pages**: Individual pages for each animal, including images and information.
- **Responsive Navigation**: The navigation changes based on the page you're on (e.g., on animal detail pages, only the Home button is visible).

## Technologies Used

- HTML
- CSS (with modern design techniques)
- JavaScript (for dynamic behavior on animal detail pages)

## How to View the Project

1. Clone the repository or download the files to your local machine.
2. Open the `index.html` file in your web browser to view the homepage.
3. Navigate to any animal's detail page (e.g., `lion.html`) to view more information.

## How to Run the Project Locally

To run this project locally on your machine:

1. Clone the repository or download the files from GitHub.
2. Open the `index.html` file with any web browser (e.g., Chrome, Firefox).
